# Silas Dawson - Portfolio

A modern, responsive portfolio website showcasing projects, skills, and experience.

## Features

✨ **Modern Design** - Clean and contemporary UI with smooth animations
🎨 **Responsive Layout** - Works perfectly on desktop, tablet, and mobile devices
⚡ **Smooth Interactions** - Scroll animations and hover effects
🎯 **Easy to Customize** - Simple structure to add your projects and information

## Sections

- **Hero** - Eye-catching introduction with call-to-action
- **About** - Brief professional summary
- **Projects** - Featured projects with descriptions and technologies
- **Skills** - Organized skill categories
- **Contact** - Multiple ways to get in touch

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Customize content with your information
4. Update social media links in the contact section
5. Deploy to GitHub Pages or your preferred hosting

## Customization

### Update Personal Information
- Edit the hero section heading and tagline
- Update the about section text
- Add your real projects to the projects grid
- Update social media links

### Styling
- Colors are defined as CSS variables in `styles.css` (`:root`)
- Main color scheme: Blue (`#0066cc`) and Cyan (`#00d4ff`)
- Dark theme with modern gradient accents

### Projects
- Add more project cards by duplicating the `.project-card` div
- Update project titles, descriptions, and technologies
- Add links to live projects or GitHub repositories

## Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, Animations)
- Vanilla JavaScript
- Responsive Design

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- Mobile browsers

## Deployment

### GitHub Pages
1. Go to repository Settings
2. Scroll to GitHub Pages
3. Select main branch as source
4. Your site will be published at `https://silasdawson.github.io/portfolio`
